# Integrating AI LLM into LangGraph

Ab tak humne ek graph ka flow create kiya the , nodes ko edges ke through ek dusre ke saath attach karke. Ab hum LLM model ko is graph mein add karenge jisse ye graph AI model ko use karega response generate karne ke liye.

```chat.py```:
```
from typing import Annotated, TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain.chat_models import init_chat_model



# Defining the state.

class State(TypedDict):
    # Define messages (a list type, with the add_messages function used to append messages)
    messages: Annotated[list, add_messages]

# Adding LLM model to Graph

llm = init_chat_model(model="gemini-3-flash-preview", model_provider="google_genai", api_key="XXXX")

#Defining the Nodes.

def chatbot(state: State):
    response = llm.invoke(state.get("messages"))
    return {"messages": [response]}


def sample_node(state: State):
    response = llm.invoke(state.get("messages"))
    return {"messages": [response]}


graph_builder = StateGraph(State)

#Adding nodes to the graph

graph_builder.add_node("chatbot", chatbot)
graph_builder.add_node("sample_node", sample_node)


# Connecting nodes through edges

graph_builder.add_edge(START, "chatbot")
graph_builder.add_edge("chatbot", "sample_node")
graph_builder.add_edge("sample_node", END)

# Compiling the graph

graph = graph_builder.compile()

# Invoke the graph

updated_state = graph.invoke(State({"messages": ["My name is Puneet Verma"]}))

print("\n\n Final State: ", updated_state)

# Flow: (START) --> chatbot --> sample_node --> (END)

# state = {"message": ["Hey There!"]}
# node runs chatbot(state: ["Hey There!"]) --> returns ["Hey This message is from chatbot node."]
# node runs sample_node(state: ["Hey There!", "Hey This message is from chatbot node."]) --> returns ["Hey This message is from sample_node node."]
# state = {"message": ["Hey There!", "Hey This message is from chatbot node.", "Hey This message is from sample_node node."]}
```
