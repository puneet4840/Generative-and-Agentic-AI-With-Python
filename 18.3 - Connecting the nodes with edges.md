# Connecting the nodes with edges

Pichle slide mein node create kiye the, ab is slide mein un nodes ko edges ke thorugh connect karenge. Jisse ek graph workflow ban jayega aur graph usi sequence mein run hoga.

<br>

Folder Structure:
```
LangGraph
|- chat.py
```

```chat.py```:
```
# Connecting nodes through edges

graph_builder.add_edge(START, "chatbot")
graph_builder.add_edge("chatbot", "sample_node")
graph_builder.add_edge("sample_node", END)
```

<br>

**Complete Code**:

```chat.py```:
```
from typing import Annotated, TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages

# Defining the State

class State(TypedDict):
    # Define messages (a list type, with the add_messages function used to append messages)
    messages: Annotated[list, add_messages]


# Defining the Nodes

def chatbot(state: State):
    return {"message": ["Hey This message is from chatbot node."]}


def sample_node(state: State):
    return {"message": ["Sample message appended."]}


graph_builder = StateGraph(State)

# Adding nodes to the graph

graph_builder.add_node("chatbot", chatbot)
graph_builder.add_node("sample_node", sample_node)


# Connecting nodes through edges

graph_builder.add_edge(START, "chatbot")
graph_builder.add_edge("chatbot", "sample_node")
graph_builder.add_edge("sample_node", END)

# Flow: (START) --> chatbot --> sample_node --> (END)

```

Explanation:
- Node ko edges se connect kar diya, Isme START aur END node predefined nodes hote hain jo graph form karne ke liye use karna mandatory hota hai.

## Compiling the graph

Graph complete build hone ke baad usko compile kiya jata hai.

```chat.py```:
```
# Compiling the graph

graph = graph_builder.compile()
```

<br>

**Complete Code**:

```chat.py```:

## Test Run the Graph

Graph ko run karne ke liye usko invoke karna padta hai. Invoke karne se jis way mein graph ke nodes connect kiye hain vo vaise hi run hota hai.

```chat.py```:
```
# Invoke the graph

updated_state = graph.invoke({"message": ["My name is Puneet Verma"]})

print("\n\n Final State: ", updated_state)
```

<br>

```
from typing import Annotated, TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages


# Defining the state.

class State(TypedDict):
    # Define messages (a list type, with the add_messages function used to append messages)
    messages: Annotated[list, add_messages]


#Defining the Nodes.

def chatbot(state: State):
    return {"message": ["Hey This message is from chatbot node."]}
```
