# Chain of Thought Prompting

Chain of Thought Prompting (CoT) ek advanced prompting technique hai jisme hum AI ko direct final answer dene ke bajaye problem ko step-by-step logically analyze karne ke liye guide karte hain. Is technique ka purpose ye hota hai ki AI answer tak pahunchne ka poora reasoning path follow kare.

Isme LLM khud se sochta hai ki user ke question ko kaise solve karna hai, konsa response best hoga user ke liye.

Isme hum AI ko direct answer dene ke bajaye problem ko step-by-step sochne ke liye guide karte hain. LLM model step-by-step sochta hai fir response deta hai.

Iska main goal ye hota hai ki AI sirf final output na de, balki us answer tak pahunchne ka logical process bhi follow kare.

<br>

Agar tum AI se seedha sawal poochte ho, to wo mostly direct answer deta hai. Lekin jab tum usko specifically bolte ho ki “step by step socho” ya “reasoning ke saath answer do,” to AI problem ko multiple logical steps mein todta hai.

**Example**:

Normal Prompt:
```
“Server ke paas 16GB RAM hai aur 4 apps 2GB each use kar rahi hain. Kitni RAM bachi?”
```
Direct answer:
```
8GB
```

Lekin Chain of Thought Prompt mein AI is tarah sochega:
- Total RAM = 16GB
- Har app = 2GB
- 4 apps total usage = 4 × 2 = 8GB
- Remaining RAM = 16 - 8 = 8GB

Isse user ko sirf answer nahi milta, balki us answer ke peeche ka logic bhi samajh aata hai.

<br>
<br>

### Chain of Thought Ka Main Goal

Chain of Thought ka primary goal hai complex problems ko smaller reasoning steps mein divide karna. Ye especially tab useful hota hai jab task difficult ho, jaise:
- Math problems
- Kubernetes troubleshooting
- Azure debugging
- System design
- Security analysis
- Decision making

<br>
<br>

### Chain of Thought Ka Basic Formula

CoT generally is pattern par kaam karta hai:

**Problem** → **Breakdown** → **Logical Steps** → **Final Answer**

Ye approach AI ko organized reasoning deta hai.

<br>

### CoT Prompt Kaise Likhen?

Strong CoT prompts mein usually ye words use karte hain jaise:
- Step by step
- Break it down
- Analyze layer by layer
- Explain reasoning
- First think, then answer

<br>

### Chain of Thought Prompting Examples

<br>

**Example 1: Basic Math Problem**:

Normal Prompt:
```
“Ek car 120 km 2 ghante mein travel karti hai. Speed batao.”
```
Direct Answer:
```
60 km/h
```

Chain of Thought Prompt:
```
“Step by step solve karo: Ek car 120 km 2 ghante mein travel karti hai. Speed kya hogi?”
```

AI Reasoning:
- Speed ka formula = Distance / Time
- Distance = 120 km
- Time = 2 hours
- Speed = 120 ÷ 2 = 60 km/h

Final Answer:
```
60 km/h
```

Why Better?
- Yahan tumhe sirf answer nahi mila, balki formula aur calculation process bhi samajh aaya.

<br>

**Example 2: Kubernetes Pod Pending Issue**:

Normal Prompt:
```
“Kubernetes pod pending kyun hai?”
```
Generic Answer:
```
Node resources ya scheduling issue ho sakta hai.
```

Chain of Thought Prompt:
```
“Kubernetes pod Pending state mein hai. Step by step possible causes analyze karo from scheduler, node resources, taints, PVC, and events.”
```

AI Reasoning:
- kubectl describe pod run karo
- Scheduler events check karo
- Node CPU/Memory available hai ya nahi
- Taints/Tolerations mismatch hai ya nahi
- PVC bound hai ya nahi
- Namespace quota issue hai ya nahi

Final Answer:
```
Most likely root cause events section se identify hoga.
```

<br>

**Example 3: Azure App Service 403 Error**:

Normal Prompt:
```
“Azure App Service 403 fix karo”
```

Weak Output:
```
Access restrictions check karo.
```

Chain of Thought Prompt:
```
“Googlebot ko Azure App Service se 403 mil raha hai. Step by step troubleshoot karo using access restrictions, WAF, robots.txt, middleware, and rewrite rules.”
```

AI Reasoning:
- Access Restrictions blade check karo
- SCM site restrictions verify karo
- Front Door ya WAF policies check karo
- robots.txt allow/disallow review karo
- User-Agent blocking rules inspect karo
- web.config / middleware rewrite rules analyze karo

Final Answer:
```
Sabse pehle IP restrictions aur rewrite rules inspect karo.
```

### Python example of Chain-Of-Thought prompting

```cot.py```:
```
# Few-Shot Prompting

from openai import OpenAI
client = OpenAI(
    api_key="XXXX",
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/"

)

Sytem_Prompt = """
You are an expert Ai Assistant in resolving user queries using Chain of Thought prompting technique. You will be given a question and you have to break down the question into multiple steps and then answer the question.

You work on START, PLAN and OUTPUT steps.

Example-1:
Question: If there are 3 cars and each car has 4 wheels, how many wheels are there in total?
START: I will first calculate the number of wheels in one car and then multiply it by the number of cars.
PLAN: Number of wheels in one car = 4
Number of cars = 3
OUTPUT: Total number of wheels = Number of wheels in one car * Number of cars = 4 * 3 = 12

"""

response = client.chat.completions.create(
    model="gemini-3-flash-preview", 
    messages=[
        {"role": "system", "content": Sytem_Prompt},
        {"role": "user", "content": "Hey, Write a python code to add n numbers."}
    ]
)

print(response.choices[0].message.content)
```
